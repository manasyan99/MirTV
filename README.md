# Мир ТВ — бесплатное ТВ, радио и свои плейлисты на Android

Аналог сайта famelack.com для телефона.

## Что умеет
- 📺 ТВ-каналы по странам и категориям (каталог iptv-org)
- 📻 Радиостанции по странам (каталог Radio Browser)
- 📋 «Свой список» — вставьте ссылку на любой M3U-плейлист (например, вебкамеры)
- ★ Избранное (хранится на телефоне)
- 🎲 Кнопка «Случайный»
- Поиск, полноэкранный режим, всё на русском

## Как получить APK (без Android Studio)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите «+» → **New repository**. Название: `MirTV`. Нажмите **Create repository**.
3. Распакуйте этот архив на компьютере.
4. В репозитории нажмите **uploading an existing file** и перетащите ВСЁ содержимое папки MirTV (включая папки `app` и `.github`).
   - Если папку `.github` не видно (на Mac скрытые папки показываются по Cmd+Shift+.), создайте файл вручную: **Add file → Create new file**, в имени напишите `.github/workflows/build.yml` и вставьте туда содержимое файла build.yml.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions** — сборка запустится сама (3–6 минут). Дождитесь зелёной галочки ✅.
7. Откройте раздел **Releases** (справа на главной странице репозитория) → скачайте файл **MirTV.apk**.
8. Откройте файл на телефоне, разрешите установку из этого источника — готово.

Если сборка упала (красный ❌) — откройте её, скопируйте текст ошибки и пришлите мне, я исправлю.

## Ограничения
- Часть каналов может не работать: потоки бывают отключены или доступны только в определённой стране.
- Радио не играет при выключенном экране надолго (отдельной фоновой службы нет).
- Это неофициальное приложение, не связанное с Famelack. Контент берётся из открытых каталогов, сами потоки принадлежат их владельцам.
